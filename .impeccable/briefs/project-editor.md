# Project editor surface brief

- Mode: Operate
- Scope: authenticated dashboard plus the desktop project editor vertical slice
- Audience: creators finishing an already-edited master video
- Task: understand, approve, revise, preview, and export evidence-backed motion overlays without changing the source edit
- Proof: a working locked-source player, editable motion plan, timeline interaction, scoped prompt revision, generated HyperFrames fixture, and verified exports
- Constraints: near-black calm workspace, compact controls, WCAG AA, deterministic render state, no invented claims, no dead controls disguised as working
- Direction: Post-production light table. The video is the illuminated plate; motion plans are registered acetate annotations; timing, evidence, and protection marks share one precise editorial grid.
- Memorable moment: selecting a motion cue illuminates its exact transcript evidence, protected regions, overlay bounds, and timing range across preview, inspector, and timeline at once.
- Signature interaction: transcript, preview overlay, motion track, and inspector remain selection-synchronized.
- Unresolved: production identity provider, cloud object-storage vendor, speech/vision provider, and deployment target remain adapter decisions.

## Direction contract

WORLD: A modern optical finishing bench translated into compact screen-native controls—charcoal metal, graphite rails, warm-white type, and one electric chartreuse registration color.

FIRST VIEWPORT: The editor opens already at work. The source frame dominates the center, framed by a slim tool rail, evidence inspector, and a dense multitrack timeline. No welcome hero or generic metric grid interrupts the job.

VISITOR PATH: Inspect the selected suggestion, understand why it is proposed, approve or reject it, prompt a surgical revision, compare the new version, then export through an explicit QC gate.

SIGNATURE INTERACTION: One selected motion cue lights up everywhere—canvas bounds, transcript excerpt, timeline segment, source evidence, and revision scope—using the same registration accent.

CROSS-SURFACE REACH: Dashboard thumbnails become miniature contact sheets; jobs use lab-state language; brand presets become calibrated film stocks rather than decorative themes.

HONEST RISK: Dense professional chrome can become visually noisy. The build protects the source frame with strict hierarchy, few container styles, and a single accent.

RAISE — HyperCard: Keep authoring and viewing adjacent; every selected graphic exposes editable content without changing modes.

RAISE — Orizuru sequence: Make every revision recoverable and every state transition legible.

RAISE — Phosphor terminal: Let background jobs narrate themselves with compact, time-stamped status instead of ornamental loaders.
